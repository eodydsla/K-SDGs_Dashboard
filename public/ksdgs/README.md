## 취급 규칙

- **이미지를 변형하지 않는다.** 색상 변경, 자르기, 텍스트 덮어쓰기 금지.
  달성도 막대 등 상태 표시는 이미지 **바깥**(카드 하단 캡션)에 둔다.
- 각 목표의 대표색은 `sheets/goals.csv`의 `color`에 K-SDGs 공식값으로 들어가 있다.
  UN-SDGs 팔레트와 미세하게 다르므로(예: 목표1 UN `#E5243B` vs K-SDGs `#EA1D2D`) 섞어 쓰지 않는다.
- 대외 공개 전 지속가능발전포털 운영기관에 사용 범위를 확인할 것.
